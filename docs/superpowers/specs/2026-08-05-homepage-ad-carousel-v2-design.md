# 首页紧凑轮播广告设计

## 目标

将现有文章广告改为仅在首页第一页、未筛选分类时显示的紧凑轮播横幅。广告不能成为第二个首页 Hero，必须遵循现有主题色、边框、文字和阴影变量，并兼顾桌面与移动端。文章详情页不再显示广告。

## 视觉方向

- 横幅占用首页内容栏完整宽度，高度固定为桌面 `10.25rem`（约 164px）、移动端 `8.25rem`（约 132px）。
- 广告图片铺满横幅，以 `object-fit: cover` 裁切；左侧叠加使用 `--c-bg-2` 和透明度混合的渐变，保证暗色、浅色和动态主题均可读。
- 文案只保留角标、标题、一行说明和一个动作，避免大面积空白和多层按钮。
- 左右切换按钮为小型悬浮按钮，底部使用细小分页圆点。横幅之后紧接分类/排序工具和文章列表。
- 如果有有效广告，广告占用首页头部展示槽并替代推荐文章轮播，避免两个大轮播堆叠；没有广告时恢复现有 `PostSlide`。

## 数据契约

每条广告继续使用现有字段，并增加：

```ts
interface ArticleHeaderAd {
  id: string
  enabled: boolean
  label: string
  title: string
  description: string
  image: string
  action: 'link' | 'wechat'
  href: string
  wechatQr: string
  wechatId: string
  wechatNote: string
}
```

兼容旧配置：`action` 默认 `link`，微信字段默认空字符串。

启用广告时：

- 所有类型都必须有标题和横幅图片。
- `link` 类型必须有 `href`。
- `wechat` 类型必须有 `wechatQr`；微信号和提示语可选。
- URL 与图片字段继续拒绝反斜杠、控制字符、协议相对 URL 和非 HTTP(S)/站内根路径。

## 交互

- 多条广告每 5.5 秒自动轮播。
- 鼠标悬停、键盘焦点进入、页面不可见、微信弹层打开或系统启用减少动画时暂停。
- 左右按钮、分页圆点和移动端左右滑动支持手动切换；自动轮播提供显式暂停/继续按钮。
- 自动切换不写入屏幕阅读器 live region，只有用户手动切换时才播报当前广告。
- 普通广告使用 NuxtLink，外链添加 `noopener sponsored`，站内链接使用 `sponsored`。
- 微信广告点击后打开 Teleport 到 `body` 的模态框，显示二维码、提示语和可选微信号复制按钮。
- 模态框支持关闭按钮、点击遮罩、Escape；打开时聚焦关闭按钮，关闭后焦点返回广告。

## 后台配置

- “文章广告”改名为“首页广告”，文案明确只展示于首页文章列表上方。
- 每条广告新增动作类型选择。
- 链接类型显示广告链接；微信类型显示二维码、微信号和提示语。
- 保存前在客户端显示中文行内错误并聚焦第一个错误字段，不再展示 Zod 原始 JSON。
- 后台预览使用与前台一致的紧凑比例和主题变量。

## 组件边界

- 删除文章详情页中的广告挂载。
- 用 `HomeAdCarousel.vue` 替代职责含混的 `PostHeaderAd.vue`。
- 新建纯函数工具判断广告是否可展示，首页与组件共享同一规则，不在客户端导入完整 Zod schema。
- Schema 仍是后台 API 与配置发布的唯一写入契约。

## 测试

- Schema：旧配置默认值、链接类型、微信类型、必填字段与危险 URL。
- 静态边界：首页条件挂载、替代推荐轮播、文章详情无广告、组件包含自动暂停与微信弹层。
- 后台 E2E：切换微信类型、缺二维码时中文行内提示、填写后提交正确 payload。
- 前台 E2E：1440px 和 390px 下高度、无溢出、自动/手动轮播、微信弹层、文章详情无广告。
- 完整 `pnpm verify`、Pages Preview 与生产探针。
