# 随心听迷你控制台设计

## 目标

将全局“随心听”播放器从常驻大卡片改为用户已选定的 **C 方案：迷你控制台**。默认状态只承担快速识别与播放控制，不遮挡博客内容；时间、音量和播放模式进入显式展开态。

## 产品定位

- **对象**：访问 fly living 的桌面端与移动端读者。
- **单一任务**：在不中断阅读的前提下，快速查看当前歌曲并完成上一首、播放/暂停、下一首操作。
- **非目标**：不新增完整歌单抽屉、不改歌单数据结构、不改解密或上传流程、不引入新的字体或 UI 依赖。

## 选定方向

采用原型 C“迷你控制台”：

```text
┌──────────────────────────────────────┐
│ [42 封面] 歌名 / 艺术家   ◀  ●  ▶ │
│          ━━━━━━━ 细进度轨道 ━━━━━  │
└──────────────────────────────────────┘
```

默认桌面尺寸为约 `330 × 60px`。点击封面与曲目信息后，在同一宽度内向上/下展开详情，而不是把默认播放器长期维持为完整面板。

## 视觉系统

生产实现继续使用现有主题语义变量，保证所有主题一致工作。以下颜色仅用于说明视觉角色：

- **Night Ink** `#121722`：深色主题控制台基底映射到 `--c-bg-2`。
- **Frost Glass** `#F7F8FB`：浅色主题半透明基底映射到 `--c-bg-2`。
- **Signal Iris** `#6D5DFB`：主播放按钮和进度映射到 `--c-primary`。
- **Quiet Slate** `#6B7280`：艺术家、时间映射到 `--c-text-2`。
- **Hairline Mist** `#D8DCE6`：边框映射到 `--c-border`。

字体沿用站点现有字体栈，不加载新资源。歌名使用站点正文粗体；艺术家与时间使用较小字号和数字等宽特性。

## 组件结构

`app/components/music/GlobalPlayer.vue` 保持单组件边界，但内部拆成三个清晰区域：

1. **控制台主行 `.music-player-console`**
   - 曲目信息切换按钮：圆角方形封面、歌名、艺术家。
   - 快速控制：上一首、播放/暂停、下一首。
2. **进度轨 `.music-progress-rail`**
   - 始终显示，视觉高度约 3px。
   - 继续使用原生 range，保留键盘与屏幕阅读器操作。
3. **详情区 `.music-player-details`**
   - 仅在 `store.expanded` 时渲染。
   - 显示当前时间/总时长、静音与音量、顺序/随机模式。

不修改播放 Store 的音频生命周期、错误跳歌逻辑、跨域 API 解析或本地状态版本。

## 尺寸与布局

### 桌面默认态

- 宽度：`20.625rem`（330px），受 `100vw - 2rem` 限制。
- 主行最小高度：`3.5rem`；包含进度轨后总高约 60px。
- 封面：`2.625rem`（42px），圆角方形，不再做黑胶式旋转。
- 播放按钮：约 32px；上一首/下一首约 30px。
- 标题与艺术家均单行省略。

### 展开态

- 宽度不变。
- 详情区通过边界线与主行分隔。
- 时间、音量、模式顺序明确，不复制封面和大标题。
- 总高度控制在约 170px 内。

### 移动端

- 保留现有“从共享浮动面板按需打开”的性能策略。
- 打开后的默认态高度小于 80px，不恢复大卡片。
- 宽度为视口减去约 1.2rem，两侧留安全边距。
- 三个播放控制保持至少 44px 触控热区；视觉图标仍保持紧凑。
- 展开详情是用户主动动作，关闭或切换路由后仍按现有逻辑收起。

## 交互

- 点击曲目信息：展开/收起详情，`aria-expanded` 与状态同步。
- 上一首、播放/暂停、下一首：行为保持不变。
- 进度轨：默认可拖动；键盘方向键可调节。
- 展开态音量：支持静音按钮、滑杆及百分比输出。
- 播放态：主播放按钮出现克制的主色环/高光；封面不持续旋转。
- 加载态：继续使用加载图标；遵守 `prefers-reduced-motion`。

## 视觉签名

播放器的记忆点是底边的 **Signal Rail 信号轨**：一条极细的主题主色进度线沿控制台下缘推进。它同时表达播放状态与“迷你控制台”的仪表感，替代大封面旋转和厚重面板装饰。

## 无障碍与兼容

- 保留 `aria-label="随心听播放器"`。
- 曲目信息按钮使用明确的“展开/收起播放器详情”名称和 `aria-expanded`。
- 所有按钮保持可见焦点；移动端触控目标不小于 44px。
- 强制颜色模式下继续依赖现有 `.music-player` 边框规则。
- 减少动态偏好下禁用非必要状态动画。
- 正式域与 Pages 备用域继续使用既有歌单 API 路由逻辑。

## 测试策略

- 单元/静态契约：验证默认态结构、详情区条件渲染、尺寸标记、音量不再常驻、移动打开逻辑不回退。
- E2E 桌面：验证几何尺寸、控制可用、展开前后高度、音量仅在展开后出现。
- E2E 移动：验证初始隐藏、打开后高度小于 80px、无横向溢出、播放与下一首可用。
- 生产验证：正式域与备用域均检查播放器 DOM、几何、歌单 200、音频 206、点击后进入播放态。
