# 首页紧凑轮播广告验收标准

- [ ] 首页第一页且未筛选分类时，有有效广告则显示一套轮播横幅。
- [ ] 有广告时不同时显示推荐文章轮播；无广告时推荐文章轮播保持原行为。
- [ ] 文章详情页不存在广告组件、广告空白或广告配置文本。
- [ ] 桌面横幅高度为约 164px，移动端约 132px；390px 下无横向溢出。
- [ ] 横幅颜色、边框、阴影和文本使用站点主题变量，浅色/深色主题均可读。
- [ ] 多广告支持 5.5 秒自动轮播、左右按钮、分页圆点和移动端左右滑动。
- [ ] 自动轮播提供显式暂停/继续按钮；屏幕阅读器只播报用户手动切换。
- [ ] 悬停、焦点、后台标签页、减少动画和微信弹层会暂停自动轮播。
- [ ] 普通链接广告保持站内/站外跳转与 sponsored rel 语义。
- [ ] 微信广告点击后显示该广告独立配置的二维码、提示语和可选微信号。
- [ ] 微信弹层可通过关闭按钮、遮罩和 Escape 关闭，并恢复焦点。
- [ ] 后台可在链接与微信两种动作间切换，并只显示相关字段。
- [ ] 启用广告缺标题、图片、链接或二维码时显示中文行内错误并阻止提交。
- [ ] 旧广告配置无需手动迁移即可解析为链接类型。
- [ ] Schema、Nuxt 单测、Worker 测试、类型检查、静态生成、链接与密钥检查全部通过。
- [ ] Pages Preview 和生产部署成功，生产首页可见，文章页不可见。
