# AI 阅闻自有预览图验收标准

## AC-01 正文图片保留

当聚合详情页正文区域存在真实 `<img>` 时，图片通过安全下载后写入 R2，并由列表或阅读 API 返回。

## AC-02 来源元数据卡片拒绝

当页面仅通过 `og:image`、`og:image:secure_url` 或 `twitter:image` 提供图片时，该图片不得写入 `news_documents.images_json`，不得出现在公开 API 或页面中。

## AC-03 正文优先

当页面同时包含来源站元数据卡片和正文图片时，只保留正文图片，元数据卡片不得下载或展示。

## AC-04 历史正文保护

历史全文文档在图片重新同步或清理后，`body_text` 与 `content_mode=full` 保持不变。

## AC-05 本站卡片

无 `coverImage` 的列表项展示 fly living 自有卡片。卡片只使用本站名称、AI 阅闻栏目、当前新闻标题、本站分类和发布日期，不显示来源名称、来源域名、来源编号或来源 Logo。

## AC-06 阅读页语义

阅读页只展示真实正文图片；没有正文图片时不显示来源预览卡或伪造正文图，正文及原文链接保持可用。

## AC-07 生产数据清理

自动来源文档的旧图片引用被清空后，按新策略重新同步。公开 API 中不再返回已知在花标题卡；正常正文图片仍可返回并成功加载。

## AC-08 验证门禁

新闻专项测试、API Worker 全套测试、类型检查、变更文件 Lint、秘密扫描、部署和桌面/移动端浏览器验收全部通过。
