# fly living 周期 3 验收标准：天气、随心听与模块管理

- 日期：2026-08-03
- 状态：执行中
- 依据：`docs/superpowers/specs/2026-08-03-fly-blog-content-platform-design.md`
- 范围：固定站长城市天气、Open-Meteo 缓存与降级、歌单后台、R2 音频与封面、全站播放器、模块开关与排序、相关生产部署

## 1. 城市天气

### C3-AC-01 固定城市而非访客定位
后台只允许站长搜索并选择一个固定城市；公开站点不请求浏览器定位权限，不保存访客经纬度。

### C3-AC-02 城市搜索
管理员可按城市名搜索 Open-Meteo 地理编码结果；结果包含展示名、国家或地区、纬度、经度和 IANA 时区，空查询和异常结果被拒绝。

### C3-AC-03 天气配置走 PR
选择城市、启停天气或修改时区时，后台生成 `config/site/weather.json` 的受控 PR，不直接写入生产分支。

### C3-AC-04 配置校验
启用天气时城市名、经纬度和时区必须完整有效；禁用状态允许坐标为空；服务端拒绝任意路径和无效经纬度。

### C3-AC-05 当前天气
公开 API 返回当前温度、天气状态、昼夜、当日最高与最低温度、简短生活提示、城市、时区、更新时间和来源署名。

### C3-AC-06 缓存
正常天气结果在 D1 保存，并使用 Cache API/HTTP 缓存 30 分钟；缓存命中不重复请求上游。

### C3-AC-07 24 小时降级
Open-Meteo 失败时继续返回 24 小时内最后一次成功数据，明确标记 `stale=true` 和最后更新时间；超过 24 小时后返回可理解的暂不可用状态，不伪造温度。

### C3-AC-08 天气组件
启用时在博客右侧栏显示天气卡片；禁用或配置不完整时不显示空卡片；移动端可在侧栏抽屉正常查看。

### C3-AC-09 昼夜表现与减少动效
天气卡片根据 `isDay` 使用柔和昼夜氛围，且 `prefers-reduced-motion` 下不运行持续动画。

### C3-AC-10 来源署名
天气卡片和 API 保留 Open-Meteo 来源说明与可访问原链接。

## 2. 随心听与歌单

### C3-AC-11 歌单数据模型
`content/playlists/default.json` 使用稳定 schema，歌曲包含唯一 ID、标题、作者/来源、音频 URL、可选封面 URL、可选时长、启用状态和排序值。

### C3-AC-12 URL 安全
音频和封面仅接受公开 `http/https` URL，拒绝 `javascript:`、内网、环回、私网和受保护流媒体临时地址。

### C3-AC-13 歌单读取
后台从私有 GitHub 读取当前歌单及 SHA；未知字段不会静默丢失，损坏配置返回明确错误。

### C3-AC-14 歌单保存
管理员可新增、编辑、删除、启停和排序歌曲；保存使用 Git SHA 冲突检测并直接创建最小化 Commit。

### C3-AC-15 R2 音频与封面
歌单编辑器可打开媒体选择器，上传或选择 `music` 音频与图片；音频类型、签名和大小继续由周期 1 媒体服务校验。

### C3-AC-16 播放器全局存在
当音乐模块启用且存在可播放歌曲时，默认布局显示全局播放器；路由切换不会销毁当前队列和播放状态。

### C3-AC-17 基础控制
播放器支持播放/暂停、上一首、下一首、进度跳转、音量、静音、展开/收起。

### C3-AC-18 播放模式
播放器支持顺序循环和随机模式；随机模式避免在多首歌时立即重复当前歌曲。

### C3-AC-19 自动播放约束
首次加载不强制自动播放；浏览器阻止播放时保持暂停并提示用户交互，不循环报错。

### C3-AC-20 播放失败降级
单曲加载/播放失败时标记错误并自动尝试下一首，最多遍历队列一次；全部失败时停止并显示可恢复提示。

### C3-AC-21 状态持久化
当前歌曲、进度、音量、模式和展开状态保存到本地；刷新后恢复偏好，但不违反浏览器自动播放规则。

### C3-AC-22 播放动效
唱片封面仅在实际播放时旋转；暂停、错误或减少动态效果时停止旋转。

### C3-AC-23 键盘与语义
所有播放器按钮有可读标签、可见焦点；进度和音量使用语义化控件，主要操作不依赖悬停。

### C3-AC-24 合法来源边界
后台提示只上传站长拥有、获授权或可合法公开播放的音频；不提供第三方受保护音频抓取功能。

## 3. 模块管理与站点设置

### C3-AC-25 模块可视化管理
`/admin/modules` 以卡片或列表显示全部模块名称、说明、启用状态和顺序，不要求直接编辑 JSON。

### C3-AC-26 排序唯一
模块顺序通过上移/下移或等价控件调整，提交前重新生成连续且唯一的排序值。

### C3-AC-27 模块配置走 PR
模块开关和排序保存为 `config/site/modules.json` 的受控 PR，展示 PR 号、分支和审核入口。

### C3-AC-28 导航与公开组件联动
天气和音乐模块禁用时对应公开卡片/播放器隐藏；启用时按配置展示；核心文章路由不因模块配置异常而不可用。

### C3-AC-29 站点设置结构化天气表单
`/admin/settings` 增加天气城市搜索、选中结果和 PR 保存，不要求管理员手写经纬度 JSON。

### C3-AC-30 周期 3 占位移除
后台“随心听”和“模块管理”不再显示后续周期占位页，导航可直达真实页面。

## 4. 安全、测试与生产

### C3-AC-31 API 认证与 CSRF
天气搜索、歌单写入和配置 PR 写操作要求有效管理员会话、CSRF 与速率限制；公开天气和歌单读取只暴露已发布数据。

### C3-AC-32 统一错误格式
上游超时、配置损坏、Git 冲突、R2 失败和音频错误使用稳定错误码/可读提示，不清空编辑状态。

### C3-AC-33 单元与 Worker 测试
覆盖天气映射/缓存/降级、城市搜索、歌单 schema、URL 安全、Git 冲突、模块排序和播放器纯逻辑。

### C3-AC-34 浏览器 E2E
覆盖城市搜索创建天气 PR、歌单编辑保存、媒体选择、播放器控制与路由切换、模块管理创建 PR、移动端播放器/天气可用。

### C3-AC-35 既有功能回归
周期 1/2 的后台、文章、媒体、自述、瞬间、AI 阅闻、备份、首页、评论、RSS 和公开路由无阻断回归。

### C3-AC-36 生产交付
所有改动推送私有 `main`；需要的 D1 migration、API/Edge Worker 和 Pages 流水线成功；正式域名、备用域名、天气 API、播放器和后台回归通过，探针数据全部清理。
