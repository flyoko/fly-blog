# 发布任务生命周期收敛与人工关闭验收标准

## 自动收敛

- [x] 打开的 PR 检查失败后，列表刷新会把任务从 `checks_pending` 更新为 `failed`。
- [x] 失败任务保存 `CHECKS_FAILED` 和首条可读诊断，不再永久显示“检查中”。
- [x] 打开的 PR 检查成功且预览部署成功后，任务更新为 `preview_ready`。
- [x] 失败 PR 在 GitHub 重新运行成功后，重新检查可恢复为 `preview_ready` 并清除旧错误。
- [x] PR 已关闭或已合并时，任务分别收敛为 `closed` 或 `merged`。
- [x] GitHub 暂时不可用时，已有任务仍能显示，不会被错误改为终态。

## 人工关闭

- [x] 未完成 PR 任务可从后台关闭，GitHub PR 同时变为 closed。
- [x] 直接发布任务可关闭后台跟踪，但不会执行撤销提交操作。
- [x] 已关闭任务重复关闭幂等成功。
- [x] 已发布或已合并任务不能关闭。
- [x] 关闭操作要求会话、CSRF 和写限流，并写入审计日志。

## 后台体验

- [x] 活跃任务超过 20 分钟未更新时显示“长时间未更新”。
- [x] 每个可操作任务详情都有“重新检查”。
- [x] 未完成任务详情有“关闭任务”和确认对话框。
- [x] 关闭完成后记录进入“已完成”，页面选择下一项待处理任务。
- [x] 失败原因和技术详情在关闭后仍保留。

## 回归与部署

- [x] 现有文章发布前校验、检查诊断和编辑器定位测试继续通过。
- [x] 现有配置 PR、审核合并、直接发布流程继续通过。
- [x] Lint、类型检查、全部 Nuxt/共享单测和 Worker 测试通过。
- [x] 生产静态生成、冒烟、链接和敏感信息检查通过。
- [ ] 变更已合并到 `main`，GitHub Actions 成功，生产站点和 API 健康检查正常。
