# fly living 周期 2 验收标准：自述与瞬间

- 日期：2026-08-03
- 状态：已获连续实施授权
- 依据：`docs/superpowers/specs/2026-08-03-fly-blog-content-platform-design.md`
- 范围：自述内容模型与 `/me`；瞬间 D1/R2/API/后台与 `/moments`；点赞、Twikoo 评论入口、每日 Git 备份与恢复

## 1. 自述内容与前台

### C2-AC-01 自述内容集合
`content/about/profile.md`、`timeline.json`、`links.json` 均由结构校验保护；未知路径和任意 TypeScript 写入被拒绝。

### C2-AC-02 自述正文直接发布
站长可在后台编辑 Markdown 自述正文，预览后直接提交 Git；失败时保留本地内容和错误信息。

### C2-AC-03 自述结构变更走 PR
时间线、链接、模块开关与排序默认创建独立分支和 PR，不直接改写生产分支。

### C2-AC-04 `/me` 页面
正式域名与 Pages 备用域名均提供 `/me`，展示简介、正文、时间线和链接；空数据、错误数据和加载过程有明确状态。

### C2-AC-05 安全渲染
自述 Markdown 与外部链接经过协议、结构和 XSS 安全处理；禁止 `javascript:`、内网 URL 和不受控 HTML。

### C2-AC-06 响应式和可访问性
`/me` 在桌面、平板、手机、深浅主题和 reduced-motion 下可读；时间线、链接和后台表单支持键盘操作与可见焦点。

## 2. 瞬间数据模型与管理 API

### C2-AC-07 独立 D1 表
生产 D1 存在 `moments`、`moment_media`、`moment_likes`、`moment_backup_state` 和恢复/同步记录；不写入 Twikoo D1。

### C2-AC-08 创建瞬间事务
创建瞬间时正文、状态、标签、城市、音乐引用和媒体关系在一个事务中完成；任一步失败不留下半成品。

### C2-AC-09 编辑与冲突
编辑瞬间使用版本号或更新时间条件，旧版本写入被拒绝并返回可恢复的冲突响应。

### C2-AC-10 发布状态
瞬间支持 `draft`、`published`、`withdrawn`；公开 API 只返回已发布内容，撤回后立即不可公开访问但保留审计记录。

### C2-AC-11 城市级隐私
地点仅允许城市、地区和国家级文本，不接受精确经纬度；API 响应不包含 IP 或定位原始数据。

### C2-AC-12 标签与音乐引用
标签规范化、去重并受数量/长度限制；关联音乐仅保存受控 ID、标题和公开 URL 元数据。

### C2-AC-13 R2 媒体引用
瞬间只能引用存在且处于 active 状态的 R2 媒体；删除或撤回瞬间会同步引用表但不误删仍被其他内容使用的对象。

### C2-AC-14 后台列表和筛选
后台瞬间页支持分页、搜索、状态、年份和标签筛选，并显示媒体、点赞数、发布时间和最后更新时间。

### C2-AC-15 后台编辑体验
支持新建、编辑、草稿、发布、撤回、恢复草稿、媒体选择、预览和错误重试；网络失败不清空表单。

### C2-AC-16 审计与幂等
创建、编辑、发布、撤回、恢复和备份恢复均写审计日志；相同幂等键不会创建重复瞬间或重复媒体关系。

## 3. 瞬间公开页面

### C2-AC-17 `/moments` 时间线
公开页面按发布时间倒序分页，支持年份和标签筛选；首屏、加载更多、空状态、错误状态和最后成功缓存均可区分。

### C2-AC-18 `/moments/:id` 详情
每条已发布瞬间拥有稳定详情 URL；不存在、草稿、撤回内容返回 404，不泄露私有字段。

### C2-AC-19 图片画廊
多图使用响应式尺寸、懒加载、替代文本和可键盘关闭的灯箱；媒体失败不阻断正文。

### C2-AC-20 边缘缓存
公开瞬间列表和详情使用短期 Cache API；发布、编辑、撤回后相关缓存失效，后台写入后前台能及时看到变化。

### C2-AC-21 SEO 与分享
详情页生成稳定标题、描述、canonical、Open Graph 和结构化日期；草稿不进入 sitemap、feed 或搜索索引。

## 4. 点赞与评论

### C2-AC-22 匿名点赞 Cookie
首次点赞生成随机访客 Cookie，带 Secure、SameSite 和合理有效期；服务器只保存 HMAC 标识，不保存明文 IP。

### C2-AC-23 点赞去重
同一访客对同一瞬间重复点赞不增加计数；取消点赞后可再次点赞；并发请求保持计数一致。

### C2-AC-24 点赞限流
异常频率触发限流且不继续写 D1；公开点赞接口不要求管理员会话，但要求同源和有效瞬间。

### C2-AC-25 Twikoo 稳定路径
瞬间详情使用稳定 URL 和明确 `path` 初始化 Twikoo；评论数据继续写现有 Twikoo 服务，不进入内容 D1。

### C2-AC-26 评论降级
Twikoo 不可用时瞬间正文和点赞仍可用，页面显示评论暂不可用而不是白屏。

## 5. 备份与恢复

### C2-AC-27 定时备份
Worker Cron 每日检查变更；有变化时导出到 `backups/moments/YYYY/MM/YYYY-MM-DD.json`，无变化时不创建 Commit。

### C2-AC-28 备份完整性
快照包含 schemaVersion、导出时间、最后变更标识、瞬间正文/状态/标签/城市/音乐/媒体引用和校验摘要，不包含 R2 文件本体、IP、Cookie 或 Secret。

### C2-AC-29 备份幂等
同一数据版本重复运行不产生多个 Commit；失败记录在 `sync_runs`/审计日志并可重试。

### C2-AC-30 恢复预检
恢复前验证快照结构、校验摘要、目标环境和冲突；提供 dry-run 统计，不直接覆盖现有数据。

### C2-AC-31 原子恢复
确认恢复后在事务中写入，失败回滚；成功后清理公开缓存、写恢复审计并保留恢复前 bookmark/备份说明。

### C2-AC-32 Git 权限边界
备份和恢复只写白名单目录；GitHub App 安装范围与权限不扩大，快照 Commit 可追踪。

## 6. 质量、兼容与完成定义

### C2-AC-33 自动化覆盖
单元/集成测试覆盖结构校验、事务、状态权限、分页、缓存失效、点赞 HMAC 去重、备份差异检测、恢复 dry-run/回滚。

### C2-AC-34 E2E 核心路径
浏览器测试覆盖后台创建并发布瞬间、前台立即显示、详情点赞、评论入口、自述编辑/预览和结构 PR。

### C2-AC-35 现有功能回归
周期 1 后台、文章、媒体、配置 PR、首页、文章详情、归档、友链、RSS 和 Twikoo 文章评论无阻断回归。

### C2-AC-36 Secret 与隐私扫描
仓库、D1 导出、R2、静态产物、日志和 API 响应不包含 GitHub/Cloudflare Secret、会话值、明文访客标识或精确位置。

### C2-AC-37 生产真实验收
使用临时自述变更、临时瞬间、临时媒体、点赞、备份和恢复演练完成真实生产链路，随后清理所有探针数据和分支。

### C2-AC-38 部署与回滚
Quality、Pages Preview、Pages Production、Workers Production 全部成功；运维手册记录 D1 migration、Cron、缓存、备份和恢复回滚步骤。

周期 2 只有在 C2-AC-01 至 C2-AC-38 均有结果、阻断项通过、生产探针清理、代码和文档推送到私有 `main` 后完成。
