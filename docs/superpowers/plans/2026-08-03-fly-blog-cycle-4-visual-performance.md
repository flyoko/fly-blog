# fly living 周期 4 实施计划：统一视觉、动效、响应式、可访问性与性能

## 目标
在不改变已验证业务语义的前提下，统一公开博客和后台的视觉/交互质量，完整支持 reduced-motion 与移动端，收口键盘/屏幕阅读器基础和可安全完成的性能优化，并完成全平台最终部署。

## 任务

### Task 1：建立周期 4 测试基线
- 增加动效、焦点、语义、移动溢出与禁用模块零请求契约测试。
- 记录当前最大 JS chunk、入口 CSS 和关键路由资源。
- 保存桌面/移动、浅/深、reduced-motion 基线截图。

### Task 2：统一设计令牌与全局焦点
- 新增公开/后台共享交互令牌：时长、缓动、圆角、焦点环和触控尺寸。
- 统一 `:focus-visible`、forced-colors 和选区表现。
- 修正会裁剪焦点或只依赖 hover 的控件。

### Task 3：实现页面和列表轻动效
- Nuxt 页面切换淡入/小位移。
- 卡片 hover 仅作用于 hover-capable 设备。
- 瞬间/资讯首屏有限顺序显现。
- 加载/保存/错误状态使用语义反馈。

### Task 4：完整 reduced-motion
- 全局覆盖 transition/animation/scroll-behavior。
- 停止 header emoji、可变字体、天气 pulse、唱片和 loading spin 等非必要动画。
- E2E 验证计算样式和功能不受影响。

### Task 5：移动端公开站优化
- 320–430px 页面级溢出扫描与修复。
- 侧栏焦点/背景滚动/触控目标。
- 天气卡与全局播放器避让底部控制区。
- 长链接、代码、媒体和评论容器可安全滚动。

### Task 6：移动端后台优化
- 检查全部后台路由的表格、编辑器、对话框、媒体选择器和按钮排列。
- 统一单栏、sticky 操作、对话框最大高度与安全区。
- 验证横竖屏和 200% 文本放大。

### Task 7：语义与键盘审计
- 为非语义点击元素改用 button/link 或补齐键盘行为。
- 检查地标、标题、label、dialog、aria-live 和路由 announcer。
- 扩展公开和后台键盘 E2E。

### Task 8：周期新增资源懒加载
- 天气/音乐关闭时只执行可缓存的同源配置探针，不请求天气上游或创建 Audio。
- 仅启用时懒加载全局播放器；后台编辑器继续路由分包。
- 非首屏图片补齐 lazy/尺寸策略。

### Task 9：构建体积与运行性能
- 分析最大 chunk 来源和页面资源瀑布。
- 对可控周期新增代码进行动态导入或拆分。
- 记录无法安全拆分的 Nuxt Content/SQLite/搜索基础块并避免风险改造。

### Task 10：视觉与自动化回归
- 桌面/移动、浅/深、reduced-motion 截图。
- console/page/network error 审计。
- 全量 `pnpm verify`、`pnpm test:e2e`。

### Task 11：生产推送与部署
- 提交周期 4 分支并非强制快进私有 `main`。
- 等待 Quality、Pages、必要 Worker 流水线。
- 正式域名、备用域名、后台、公开 API、Twikoo 全量回归。

### Task 12：最终审计与交接
- 清理测试数据、PR、分支、会话和临时资源。
- 更新四周期最终验收、运维、回滚和性能证据。
- 最终提交/推送/部署后确认工作区与生产状态干净。
